# runit template

a copy/paste template for a runit service

Fundamentally based on [Kevin Chard][kchard]'s and [S Marden][smarden]'s instructions

### considerations

1. This template assumes that the owner of the service's script is the user who should own the process
1. Is tailored for [Void][void] Linux

[kchard]: https://kchard.github.io/runit-quickstart/
[smarden]: https://smarden.org/runit/
[void]: https://voidlinux.org/
